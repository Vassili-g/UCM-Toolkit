# Recherches sur UCM Palettes

Le [README du plugin](../../../../packages/plugin-palettes/README.md) décrit
l'utilisation actuelle. La
[spécification](./1%20Recherche%20initiale/RECHERCHE-PLUGIN-PALETTES.md)
porte les règles du moteur, de la recette, de l'écriture et de l'interface ;
elle reste ici jusqu'à son déplacement dans le paquet du plugin.

| Dossier | État |
|---|---|
| [Recette v10](./Recette%20v10/README.md) | En cours : R1 attend la décision D1 |
| [Comparaison du marché](./1%20Recherche%20initiale/RECHERCHE-CONCURRENCE-PALETTES.md) | Piste : vision simulée, sélection, jeu de départ, APCA, Display P3 |

Les recherches implémentées (moteur, recette critique, recette du moteur,
recettes v8 et v9, texte des boutons, harmonisation, direction simple, langues)
sont archivées. Leurs questions ouvertes et leurs recettes Figma en attente
sont reprises dans l'[état des recherches](../README.md).

L'export
[validation-textes-palettes.json](https://github.com/Vassili-g/UCM-Toolkit/blob/f4a1626/docs/notes/Recherches/Plugin%20Palettes/Textes%20et%20langues/validation-textes-palettes.json)
conserve les réponses du mainteneur sur les textes ; il ne doit pas être
réécrit.

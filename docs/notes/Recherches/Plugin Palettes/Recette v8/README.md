# Recette v8 d'UCM Palettes

Dossier de recherche de la recette v8 : la palette Poppy retirée du plugin
sans geste de suppression, ses variables lues comme quatre palettes « Déjà
dans le fichier », l'annulation des modifications, et cinq retouches de
Gestion et de Création.

**État.** Cause de la perte de Poppy trouvée dans le code : le bouton
« Annuler la reprise » retire la palette sans confirmation. Deux procédures
de réparation sans nouvelle version du plugin sont écrites ; le plan
d'action et ses cinq décisions attendent le mainteneur. Rien n'est
implémenté.

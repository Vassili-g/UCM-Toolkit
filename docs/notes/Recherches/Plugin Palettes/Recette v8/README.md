# Recette v8 d'UCM Palettes

Dossier de recherche de la recette v8 : la palette Poppy retirée du plugin
sans geste de suppression, ses variables lues comme quatre palettes « Déjà
dans le fichier », l'annulation des modifications, et cinq retouches de
Gestion et de Création.

**État.** Cause de la perte de Poppy confirmée : le bouton « Annuler la
reprise » retire la palette sans confirmation. La réparation passe par le
plugin : une reprise des quatre groupes de variables sous l'identifiant du
cadre orphelin. Les décisions D1 à D5 sont prises. Les lots 1 à 7 sont livrés ; Poppy
revient avec ses réglages par l'import d'une recette réparée. Restent la
recherche des réglages dans le plugin (T18) et les choix sur les deux
maquettes.

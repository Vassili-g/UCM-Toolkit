# Commandes Light/Dark et Soft/Vivid

Dossier de recherche d'UCM Palettes : où placer la commande du thème montré,
Light ou Dark, et les choix Soft, Vivid ou Les deux, pour que le designer voie
ce qu'il modifie. Le plan d'implémentation est livré pour la barre fixe, la bascule Light/Dark et
le choix du profil des cartes ; la phase 4, « Les deux » dans le Color shift,
attend la décision du mainteneur.

| Document | Contenu |

| [Plan d'implémentation](./PLAN-IMPLEMENTATION-COMMANDES-D-AFFICHAGE.md) | Les tâches à cocher pour un agent autonome, la case de la décision ouverte, les hypothèses et la recette du mainteneur |
| [Maquette du premier tour, section 4](../Texte%20des%20boutons/MAQUETTE-MODES-ET-AFFICHAGE.html) | Les modèles A à D de la commande Light/Dark ; le modèle A est validé. La maquette appartient au dossier du texte des boutons, dont elle montre aussi les solutions |
| [Notes de recette](../Texte%20des%20boutons/Archives/NOTES-RECETTE-MODES-ET-AFFICHAGE.md) et [première recherche](../Texte%20des%20boutons/Archives/RECHERCHE-TEXTE-DES-BOUTONS-ET-AFFICHAGE.md#6-la-commande-lightdark) | Archives communes aux deux sujets |

Le choix du texte des boutons, blanc ou noir par thème, est rangé dans
[Texte des boutons](../Texte%20des%20boutons/README.md) : il ajoute une ligne
aux Réglages communs, sans changer les commandes.

# Commandes Light/Dark et Soft/Vivid

Dossier de recherche d'UCM Palettes : où placer la commande du thème montré,
Light ou Dark, et les choix Soft, Vivid ou Les deux, pour que le designer voie
ce qu'il modifie. Statut : implémenté, en attente de la recette du mainteneur.
Décisions du mainteneur : le thème dans le titre fixe de la palette, des choix
d'une seule forme dans l'en-tête des cartes ouvertes et en tête du corps des
garanties, « Les deux » seulement dans le Réglage global, l'aperçu titré, la
configuration repliée après une création, et aucun cerne de marque. La question
« Les deux dans le Color shift » est close : le Color shift garde Soft et
Vivid.

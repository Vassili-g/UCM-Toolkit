Décisions prises :

- Le décompte commun est celui du relevé (arrêt à l'instance), pas celui du moteur (`findAll` à travers les instances) : le relevé annonce « a lu N layers sur M ». Le budget n'est employé que par Architect, l'exporteur ne passe aucun budget.
- La décision « library à choisir » d'Analyser se prend après le catalogue, sur les libraries que le catalogue attendait déjà, pour ne retarder ni le catalogue ni le moteur. Une prélecture la prend avant le relevé, sur les liaisons retenues de la dernière analyse (comme la Configuration).
- L'information du premier variant n'a pas de texte du designer : elle porte `faits.genre`, `layers` et `budget`, et l'écran montre la phrase générique de C42.
- Les oracles F9 suivent les décisions : Li-14 attend `library-a-choisir` sans analyse, les profils à plusieurs libraries attendent le refus, Bd1 compte le variant comme le relevé, Bd3-2 attend les variants lus quand des variants manquent et que le compte des layers est inconnu, Oc-18 et Oc-22 envoient `occupe` avec `demande`.

# E17. Faute proche de plusieurs termes

Phase E. Lire avant de commencer les règles d'exécution, les chemins et commandes et l'introduction de la phase E
dans [README.md](../README.md), puis l'« Avancement » de [E16](E16.md).

Agent : `implementeur-exigeant`. Deux appels. E17a (cases E17.2, E17.3 et l'état de galerie de E17.4) tourne pendant E16 : elle touche
Architect et le seul type `Question` de `harmonisation.ts`, qu'E16 ne modifie pas. E17b (E17.1 et l'oracle de E17.4) attend E16, qui
touche aussi `questions.ts` et `oracle.ts`.

Q-E14-4, acceptée par le mainteneur. Un mot à une lettre de plusieurs termes (`stat`, proche de `state` et de `status`) reçoit
aujourd'hui une carte qui ne propose qu'un terme. La carte propose désormais chaque terme, et le designer choisit.

Fichiers : `packages/kit/src/referentiel/harmonisation.ts` (type `Question`), `packages/kit/src/referentiel/questions.ts`, leurs tests,
`packages/kit/tests/stress/f1-noms/oracle.ts`, `src/nomenclature/projection.ts`, `src/ui/nomenclature/questions.ts`,
`src/ui/textes/nomenclature.ts`, leurs tests, un état de `packages/plugin-architect/galerie/etats/`, `packages/kit/CARTE.md`,
`packages/plugin-architect/SPEC.md` si la carte de faute y est décrite.

- [x] E17.1 La question `ecriture-du-terme` d'indice `faute` porte un champ facultatif `autres` : les autres termes à une lettre, dans
  l'ordre où le kit choisit la référence (terme UCM d'abord, puis le plus employé, puis l'ordre alphabétique). La référence reste le
  premier terme. Aucun terme n'est présélectionné. Régression : `stat` dans un fichier qui emploie `state` et `status` donne la
  référence `state` et `autres` égal à `status`.
- [x] E17.2 La projection d'Architect transmet `autres`. La carte garde son titre (« Corriger stat en state ») et ajoute une action
  par autre terme, après « Corriger », de poids `texte`. Sa réponse corrige vers ce terme.
- [x] E17.3 Textes, à reprendre tels quels :
  - action : `corrigerEn: (mot) => \`Corriger en ${mot}\``, soit « Corriger en status » ;
  - détail, ajouté après le détail de faute : « status est aussi à une lettre. » pour un terme, « status et stage sont aussi à une
    lettre. » pour deux, la liste jointe par des virgules puis « et ».
- [x] E17.4 Ajoutez l'état de galerie d'une carte à deux termes. Alignez l'oracle de F1 : les verdicts provisoires Q-E14-4 deviennent
  détectés quand la question liste le terme visé. Rejouez `npm run stress:f1` et donnez le nombre de verdicts Q-E14-4 restants.

Fin : `npm run test --workspace @ucm-kit/core` et `npm run test:paquet -- architect` passent. La régression échoue sans la correction.
Ne montez pas la version du kit.

- Kit : `packages/kit/src/referentiel/harmonisation.ts`, la question `ecriture-du-terme` reçoit `autres?: readonly string[]`. Aucun autre fichier du kit n'est touché.
- Vue : `src/messages/nomenclature.ts` (`QuestionVue` reçoit `autres?`) et `src/nomenclature/projection.ts` (`autres` est transmis seulement s'il est non vide).

Carte : `src/ui/nomenclature/questions.ts`, une action `corriger-en` de poids `texte` par autre terme, après « Corriger », dont la réponse est `corriger` vers ce terme (`autre.split('-')`) ; seule une faute porte ces actions.
- Tests : `tests/nomenclatureQuestions.test.ts` (carte à un et deux autres termes, mots collés, `autres` vide) et `tests/nomenclatureProjection.test.ts` (transmission et absence).
- Galerie : état `a-trancher-faute-de-deux-termes` dans `galerie/etats/nomenclature.cjs`, avec sa donnée locale (`stat`, `state`, `status`).
- Commandes : `npm run build --workspace @ucm-kit/core` ; `npx tsx --test` sur les deux tests (97 passent) ; `npm run test:paquet -- architect` (2374 passent, 0 échec) ; `npm run typecheck --workspace ucm-architect-plugin` sans erreur. `test:ui` non lancé.
- Reste pour E17b : E17.1 (le kit remplit `autres`), l'oracle de F1 de E17.4, la ligne de `packages/kit/CARTE.md` et la règle de `packages/kit/invariants/referentiel.md`. Ni `CARTE.md` ni `SPEC.md` d'Architect ne décrivent la carte de faute : rien à y écrire.

### E17b

E17.1 et l'oracle de E17.4 sont faits, sans commit ni montée de version.

- Kit : `questions.ts` collecte les candidats d'une faute, les classe (terme UCM, puis le plus employé, puis l'ordre alphabétique), prend le premier pour référence et range les suivants dans `autres`, en minuscules. `termes-connus.ts` reçoit `termesDeDeuxLettresAUneLettre` : l'index de `termesAUneLettre` ne garde que les termes de 3 lettres au moins, donc il ne voyait pas `bg`. Un mot de 3 lettres reçoit ces termes comme candidats ; la condition « un seul terme à 3 lettres ou plus » reste calculée sans eux.
- Écart avec la consigne du plan : `stat` ne donne pas `state` et `status`. `status` n'est pas un terme du kit depuis E16.4, et `etat`, `état` valent `state`. La régression prend `lext`, à une lettre de `left` et de `text` : le fichier emploie `text` deux fois, la référence est `text` et `autres` vaut `['left']`.
- `bgg` : la référence est `background` (`bg` vaut son terme UCM) et `autres` vaut `['lg']` (`big` vaut `lg`). Tests : `tests/questionsReferentiel.test.ts`, deux tests qui échouent sans la correction.
- Oracle : `tests/stress/f1-noms/oracle.ts`, `jugerUneFaute` compte détectée une faute dont la question liste le terme visé (ou son terme UCM) dans la référence ou dans `autres` ; `s17Brut` lit aussi `autres`.
- Rejeu `npm run stress:f1` : 22 728 cas en 186,8 s, 15 647 attendus, 15 647 détectés, 0 manqué, 0 faux constat, 1 328 provisoires dont 96 en Q-E14-4 (116 en E16). Slice : mêmes nombres qu'en E16 (198 sur 198 attendus, 214 cas). Colonne « Après E17 » ajoutée à la section « Cibles » de `MESURE-DES-FAILLES.md`.
- Documents : `packages/kit/CARTE.md` et `packages/kit/invariants/referentiel.md`.

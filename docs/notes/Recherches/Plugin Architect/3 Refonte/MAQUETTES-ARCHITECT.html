UCM Architect, refonte

Les écrans reprennent la feuille de style commune des plugins UCM : en-tête, bouton Configuration, onglets, boutons et champs sont ceux de Palettes. Le plugin harmonise l'écriture des noms et les termes employés, dans les variables et dans les composants.

Variables et composants

Le plugin lit deux familles de noms. Les variables sont les tokens : un chemin de groupes, puis un nom. Les composants ont des propriétés, et chaque propriété propose des valeurs, comme le panneau de droite de Figma les montre quand on sélectionne une instance. Un même terme peut vivre dans les deux familles : pressed dans le chemin d'une variable et comme valeur de la propriété State.

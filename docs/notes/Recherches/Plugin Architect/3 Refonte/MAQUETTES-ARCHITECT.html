UCM Architect, refonte

Le plugin harmonise les noms des variables du fichier des tokens : leur écriture et les termes qu'elles emploient. Les écrans reprennent la feuille de style commune des plugins UCM.

Troisième version : variables seulement, fiches en feuilles

Ce que le plugin renomme

Les variables locales du fichier ouvert. Une variable se lit en trois parties ; l'écriture se règle pour les groupes et pour le nom, les collections suivent les noms UCM.

components /collection
button/sizes/medium /groupes
padding-xnom

Plan de navigation

À l'ouverture
  • Fichier jamais analysé : Premier lancement, puis Écriture des noms
  • Sinon : l'onglet À appliquer
À appliquer et À trancher
  • Deux onglets ; une réponse dans À trancher ajoute des renommages à À appliquer
  • Appliquer, en bas : la feuille de confirmation
Règles
  • Modifier, sur l'écriture : sa feuille
  • Une ligne de terme : la feuille du terme
  • Remplacer par… : l'étape suivante, dans la même feuille
  • ✕, ou un clic sur le fond : la feuille se ferme
Configuration
  • Le bouton en haut à droite, comme dans Palettes
  • Il devient Retour pendant la configuration

# Recherches sur la direction artistique

Les propositions de direction artistique pour UCM Toolkit, ses plugins et les
paquets `@ucm-kit`. Elles portent sur les logos ; l'interface des plugins reste
sombre et neutre. Aucune n'est validée.

| Dossier | Contenu | Commencer par |
| --- | --- | --- |
| [1 Calage](./1%20Calage/) | Une direction tirée de l'atelier d'impression, avec ses logos, ses couvertures et ses touches dans un plugin. Le mainteneur a demandé d'autres pistes | [DIRECTION-ARTISTIQUE-UCM.md](./1%20Calage/DIRECTION-ARTISTIQUE-UCM.md) |
| [2 Pistes conceptuelles](./2%20Pistes%20conceptuelles/) | Quatre pistes construites sur des unités ordonnées : Capitule, Mise en carte, Pavillons, Graduation | [PISTES-CONCEPTUELLES.md](./2%20Pistes%20conceptuelles/PISTES-CONCEPTUELLES.md) |
| [3 Capitule](./3%20Capitule/) | La piste Capitule reprise en figures de cercles tangents : chaîne de Steiner, cercles de Descartes, chaîne de Pappus, cercles emboîtés. Le script vérifie chaque tangence | [PLANCHE-CAPITULE.html](./3%20Capitule/PLANCHE-CAPITULE.html) |

Chaque dossier garde le script qui produit sa planche. Il se lance depuis la
racine du dépôt, avec la commande écrite en tête du fichier.

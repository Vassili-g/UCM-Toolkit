Segmented control

Un groupe de 2 à 5 segments collés. Un clic sur un segment choisit une option ou change la vue.

Guide de composant, gabarit 2, du 2026-10-30. Page produite par guide.ts rendre ; ne pas la modifier à la main.

1Galerie

Les vrais composants, chargés depuis leur paquet à la version écrite sur la carte. Chaque scène montre les mêmes cas : trois libellés, icônes seules, libellé long dans 300 px, « mois » désactivé. Survolez, cliquez, et utilisez Tab puis les flèches.

Ant Design

Segmented · antd@6.6.3 · react@19.2.0 · react-dom@19.2.0
  1. Chaque segment est un vrai bouton radio caché.
  2. Les flèches sélectionnent tout de suite, et bouclent.
  3. Tab s'arrête deux fois : sur le groupe, qui ignore les flèches, puis sur le segment coché.
  4. Sans nom donné, le groupe s'annonce « segmented control », en anglais. Les segments à icône seule n'ont aucun nom.
  5. Chaque segment prend la largeur de son texte. Le libellé long sort du cadre.

Carbon

cds-content-switcher · @carbon/web-components@2.66.0 · @carbon/icons@11.91.0 · @carbon/icon-helpers@10.47.0
  1. Les segments sont des onglets, pas des radios.
  2. Les flèches sélectionnent tout de suite, bouclent, et sautent le segment désactivé.
  3. Le segment choisi est un aplat sombre. C'est la sélection la plus visible des cinq.
  4. Les segments ont tous la même largeur et remplissent le conteneur. Le libellé long chevauche son voisin.
  5. Le segment désactivé change à peine d'aspect. Les icônes seules n'ont aucun nom lu.

Radix Themes

SegmentedControl · @radix-ui/themes@3.3.0 · react@19.2.0 · react-dom@19.2.0
  1. Les flèches déplacent seulement le focus, et bouclent. Espace ou Entrée sélectionne.
  2. Tous les segments prennent la largeur du plus long. Avec le libellé long, le groupe dépasse le cadre.
  3. Un segment seul ne peut pas être désactivé. Seul le groupe entier peut l'être.
  4. Le texte choisi passe en gras sans que le segment change de largeur. Chaque libellé est rendu deux fois pour cela.

Spectrum

SegmentedControl · @react-spectrum/s2@1.8.2 · react@19.2.0 · react-dom@19.2.0
  1. Les flèches déplacent seulement le focus, sans boucler. Espace sélectionne.
  2. Le segment choisi est un contour épais sur fond blanc, posé sur une piste grise.
  3. Le groupe porte un nom, ici « Période ». Chaque icône seule porte le sien.
  4. Chaque segment prend la largeur de son texte. L'option isJustified les rend égaux.

Polaris

ButtonGroup variant="segmented" · @shopify/polaris@13.9.5 · @shopify/polaris-icons@9.3.1 · react@18.3.1 · react-dom@18.3.1
  1. Ce n'est pas un contrôle de choix. Ce sont des boutons collés, dont un est « enfoncé ».
  2. Le composant ne retient pas la sélection. Le produit doit dire quel bouton est enfoncé.
  3. Tab s'arrête sur chaque bouton. Les flèches ne font rien.
  4. Le libellé long passe sur deux lignes, et ce seul bouton grandit.

Le composant web s-button-group n'est pas publié sur npm. Ce composant React est son équivalent open source.

Material Design 3

Segmented button

Pas de version web : le segmented button existe pour Android et Flutter. Sa capture reste dans _local/, hors du dépôt public. Ses fiches retiennent une coche dans le segment choisi et une variante à choix multiple.

2Ce qu'il faut comprendre

Les différences entre systèmes qui changent ce qu'il faut dessiner.

Ce que le composant est vraiment

Le même aspect cache trois composants. Le lecteur d'écran et le clavier les traitent différemment.

Un choix parmi plusieursBoutons radio. Ant Design, Radix Themes, Spectrum.
Des ongletsChange la vue en dessous. Carbon.
Des boutons enfoncésChaque bouton est indépendant. Polaris.

À décider : Le composant choisit-il une valeur, ou change-t-il la vue ? La réponse fixe son nom pour le développeur.

Ce que font les flèches

Dans deux systèmes, la flèche sélectionne. Dans deux autres, elle déplace seulement le focus.

La flèche sélectionneLe contenu change à chaque touche. Ant Design, Carbon.
La flèche déplace le focusEspace confirme. Radix Themes, Spectrum.
Tab de bouton en boutonPas de flèches. Polaris.

À décider : Si la flèche déplace seulement le focus, il faut dessiner le focus sur un segment non choisi. Sinon, le focus se pose toujours sur le segment choisi.

Comment se répartit la largeur

Regardez le cas du libellé long. Aucun des cinq ne coupe proprement le texte dans 300 px.

Segments égauxLe plus long fixe la largeur de tous. Carbon, Radix Themes.
Largeur du texteChaque segment a sa largeur. Ant Design, Spectrum, Polaris.

À décider : Segments égaux ou au texte, et une longueur maximale de libellé. Carbon conseille deux à trois mots.

Comment se voit la sélection

Chaque système marque le segment choisi autrement. Certaines marques sont très discrètes.

Pastille claire sur piste griseÉcart de fond faible. Ant Design, Radix Themes.
Aplat sombreTrès visible. Carbon.
Contour épaisSpectrum.
Bouton grisé, enfoncéPolaris.

À décider : La marque de sélection. Elle doit se distinguer du fond avec un contraste d'au moins 3:1, ou par une autre forme qu'un écart de couleur.

Ce qui peut être désactivé, et les icônes seules

Quatre systèmes désactivent un segment seul. Radix désactive seulement le groupe. Chez Ant Design et Carbon, un segment à icône seule n'a pas de nom pour le lecteur d'écran.

Un segment désactivéAnt Design, Carbon, Spectrum, Polaris.
Le groupe seulementRadix Themes.
Icône seule nomméeRadix Themes, Spectrum, Polaris.

À décider : Autoriser un segment désactivé, ou non. Pour chaque icône seule, écrire dans Figma le texte que lira le lecteur d'écran.

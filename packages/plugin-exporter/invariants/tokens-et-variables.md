# Tokens et variables

- **Les tokens restent des références ; alias jamais aplatis.**
- **`normalizeName()` et `indexVariables()` sont communs aux deux commandes.**
- **Collision feuille/groupe ou deux chemins identiques : tranchées avant la construction de l'arbre.** Aucun alias ne pointe vers une variable rejetée. Spec : [§2]
- **Le contrat ne publie aucun index de ses tokens** : `tokensUsed` se dérivait du contrat terminé, et ce qui se dérive ne se publie pas. Consommateur : balaie les références du contrat, `samples` et `meta` exclus. Spec : [§8](../../../docs/format/FORMAT.md#8-rendu-sémantique-et-garde-fous)
- **Un nom de token se projette de trois façons, chacune avec un propriétaire, tous dans `kit/src/format/names.ts`.** `normalizeName` : chemin Figma vers token ; `codeIdentifier` : nom Figma vers identifiant de code ; `tokenCssVariable` : token vers propriété personnalisée CSS. `attributDeMode` en dérive l'attribut HTML d'un axe de modes, `axeDesExtensions` le nom de l'axe de ses collections étendues. Projection recopiée ailleurs = faute : diverge sans erreur. Borne de `tokenCssVariable` : retire les accents (un nom composé et le même nom décomposé donnent la même propriété) ; ne coupe pas sur les bosses de casse, ce qui la distingue d'un `kebabCase` de bibliothèque ; n'est pas une bijection. Spec : [§N]
- **Le chemin d'un token s'assemble dans `joinTokenPath` seul** (`kit/src/format/chemins-de-tokens.ts`, ré-exporté par `plugin-socle/src/composant/variables.ts`) : collection et variable passent par `normalizeName`, segments sans accolades ni `$` de tête, collection écrite une fois. Figma accepte ces caractères dans un nom de collection ; une référence DTCG ne sait pas les citer. Spec : [§N]
- **`tokens.json` porte la version du format de tokens à la racine du document, nulle part ailleurs** : `$extensions["com.ucm.formatVersion"]`, entier positif, écrit une fois, avant les groupes. Forme de valeur changée : numéro monté, jamais `CONTRACT_VERSION` ; chemins et alias en place. Autorité : `kit/src/format/tokens.ts` `TOKENS_FORMAT_VERSION`, seul endroit où le numéro courant s'écrit. Spec : [§2]
- **`tokens.json` déclare ses axes de modes à la racine, après la marque** : `$extensions["com.ucm.axes"]`, écrit dès qu'une feuille porte `com.ucm.modes`, `{}` quand l'export les a tous écartés. Clé d'un axe : `prefixeDeCollection`, que `joinTokenPath` emploie aussi. `modes` suit l'ordre de la collection ; `default` nomme le défaut sans le déduire de l'ordre. Feuille d'un axe retenu : le nomme dans `com.ucm.axis` ; le premier segment de son chemin ne le désigne pas. Préfixe vide ou partagé, mode sans nom ou en collision, défaut introuvable : axe écarté sous un constat. Alias d'un autre type dans un mode ou une surcharge d'extension : constaté, axe gardé. Collection à un seul mode que des collections étendues surchargent : aussi un axe. `src/tokens/exportTokens.ts` `axesDesCollections` décide pour l'export ; `kit/src/lecteurs/modes-tokens.mjs` `axesDeTokens` classe ce qu'un lecteur reçoit. Spec : [§2]
- **Le kit classe la marque avant de lire un seul token.** Absente : `origine` ; courante : `courante` ; antérieure énumérée par `VERSIONS_DE_TOKENS_LUES` : `ancienne` ; entier supérieur : `future` ; autre valeur, ou document ou `$extensions` non objet : `invalide`. `future` et `invalide` refusent le contrôle, y compris dans un repository sans contrat ; `ancienne` se lit comme `courante`. Seule la racine est lue. Borne : fenêtre énumérée, jamais déduite ; version inférieure non présumée lisible, version future non plus. Autorité : `etatDuFormatDeTokens()`. Spec : [compatibilité](../../../docs/format/COMPATIBILITE.md#la-version-du-format-de-tokens)
- **Couleur : `{ colorSpace, components, alpha }`.** Espace : `documentColorProfile`, lu une fois par export ; `LEGACY` devient `srgb` sous un seul avertissement. Composantes à la précision de Figma ; `alpha` toujours écrit.
- **Dimension : `{ value, unit: "px" }`.**
- **Chaque valeur de `com.ucm.modes` a la forme de `$value`** ; un alias reste une référence dans tous les modes.
- **Le type d'une graisse `STRING` se décide une fois par variable, sur tous ses modes et son graphe d'alias, avant la sérialisation.** Littéraux reconnus par `poidsDeGraisse()` sous un segment `fontweight` ou `font-weight`, et alias aboutissant tous à `number` donnent `number` ; variable d'alias seuls : suit ses cibles, quel que soit son nom. Tout le reste, cible absente et boucle comprises : `string`. Table des graisses jamais recopiée ; décision indépendante de tout ordre. Autorité : `src/tokens/graisses.ts` `graissesNumeriques`. Spec : [S2]
- **Le type d'une famille `STRING` se décide sur une composante connexe du graphe d'alias, tous modes confondus, jamais sur la feuille courante ni sur son nom.** Composante : `fontFamily` avec au moins une preuve positive (liaison `fontFamily` d'un text style local, ou scope `FONT_FAMILY` seul) et aucun conflit. Conflits : liaison par un autre champ de chaîne, scope de texte posé à côté de `FONT_FAMILY`, alias qui quitte l'index. Sans preuve : reste `string`. `graissesNumeriques` décide avant ; `famillesDeTokens` (`src/tokens/familles.ts`) ne voit pas ce qu'elle a retenu : ensembles disjoints. Spec : [S2]
- **`TIMING` devient une durée en secondes, sans conversion ni arrondi.** Spec : [S2]
- **`EASING` devient une courbe dès que l'API joint ses quatre points, quel que soit son `type`, s'ils sont finis et si les abscisses sont dans `[0, 1]`** ; ordonnées libres. `LINEAR` en a une par définition, un ressort jamais, même avec des points. Toute autre valeur écarte la variable entière du fichier sous un constat ; alias vers elle : politique des cibles absentes. Autorité : `src/tokens/mouvement.ts` `easingsSansCourbe`. Spec : [S2]
- **Les clés `com.ucm.*` de `$extensions` et le nom `base` d'un contexte d'axe s'écrivent par les constantes de `kit/src/format/tokens.ts`** (`EXTENSION_VERSION_TOKENS`, `EXTENSION_AXES_TOKENS`, `EXTENSION_AXE_TOKENS`, `EXTENSION_MODES_TOKENS`, `EXTENSION_SURCHARGES_TOKENS`, `MODE_DE_BASE`). Aucun littéral `'com.ucm.…'` ailleurs dans `packages/*/src`. Tests : `/tests/reglesUniques.test.ts` (D-29).
- **Un alias dont la cible n'est pas une variable que le fichier publie écrit `$value: null` et se dit une fois par variable.** Cible absente : supprimée, de library, écartée pour collision ou pour son easing. Le kit juge, sur un catalogue des seules variables locales publiées, surcharges d'extension comprises ; l'Exporter ne teste pas l'appartenance d'une cible, et `buildLeaf` n'avertit jamais. Easing écartée : phrase propre, qui nomme la cible. Autorité : `kit/src/controles/structure.ts` `controlerLesAliasesManquants`, `src/tokens/exportTokens.ts` `constaterLesAliasesManquants`. Tests : `tests/exportTokens.test.ts`. Spec : [S2]
- **Aucune valeur de l'API Figma recopiée** : `dtcgType` et `formatValue` traitent les six membres de `VariableResolvedDataType` sans branche par défaut ; un septième donne une erreur de compilation. Spec : [S2]

# Composition

- **Un composant unifié imbriqué est déclaré dans `composes`.** Critère « ce node porte les règles de X » : n'existe qu'une fois. Autorité : `rulesContainerOwner`.
- **Une dépendance est reconnue quand un conteneur posé sur la page de son maître écrit son nom** (`indexContractedNames`). Dépendance de bibliothèque : jamais ; calque `component-name` masqué dans une instance : ne compte pas. Analyse : pages de ces maîtres seulement. Tests : `loiDuDocumentIntact.test.ts` refuse `loadAllPagesAsync` dans `src/contract/`.
- **Les règles documentent sans autoriser : tout `COMPONENT` ou `COMPONENT_SET` sélectionné est exportable.** Le parent ne réexporte pas les internes d'une dépendance reconnue. Une seule chose en remonte, non normative : ce que le parent a changé par rapport au maître, soit les surcharges de `InstanceNode.overrides`, soit le remplacement d'une instance, que ce relevé ne rapporte pas et qui se lit en comparant l'instance à son maître, position par position. → [échantillon](./echantillon.md#échantillon-de-maquette)
- **Le parcours conserve le calque de l'instance pour le décrire comme un slot.** Ce qu'il porte reste hors du contrat parent. Ses couleurs appartiennent à son contrat (`getSlotTokens`) ; ses dimensions ne le font pas élire node de layout (`findLayoutNode`).
- **`composes` ne désigne que le calque qui est l'instance.** Calque qui l'enveloppe : contrat parent, publie son flux, range la dépendance dans `children`. Trois liens → trois enfants ; le cadre ne reprend une `visibilityProp` que lorsqu'une seule dépendance l'occupe. → [cadre](../../../docs/format/FORMAT.md#cadre-de-dépendance)
- **Ce cadre publie tous ses calques, pas seulement les branches de dépendance.** Chemins de typographie et signatures suivent cette réponse. Borne : cadre sans branche menant à une dépendance : ne publie rien. Autorité : `structureTree.publishesChildren`, qui tranche l'unique exception.
- **Chaque `variantViews[variants[].view].composes` se dérive de son arbre publié, dans son ordre.** `composes` global = union ordonnée à cardinalité maximale. Dépendance non située : sort des deux champs à la fois, sous avertissement. → [composition](../../../docs/format/FORMAT.md#composition-et-dépendances)

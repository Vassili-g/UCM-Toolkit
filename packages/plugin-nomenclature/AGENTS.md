# Nomenclature (`packages/plugin-nomenclature`)

Plugin UCM Nomenclature : ucm-nomenclature-plugin, privé ; renomme les variables et les collections locales.

- Écrit dans Figma : `src/ecriture.ts` seul, et seulement le `name` des variables et collections locales, ses données partagées dans `ESPACE_ARCHITECT` et le point d'annulation.
- Commandes : `npm run test:paquet -- nomenclature`, `npm run build:plugin -- nomenclature`, `npm run galerie:plugin -- nomenclature`.
- Carte : [CARTE.md](./CARTE.md).

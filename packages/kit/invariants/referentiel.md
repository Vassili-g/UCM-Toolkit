# Référentiel

- **Une définition UCM (crans, modes, profils, états, collections, rôles du thème, garanties, rôle des produits, tags des règles d'usage, conventions de noms) se modifie dans [`src/referentiel/`](../src/referentiel/), jamais dans un paquet.** Tests : `/tests/referentielUnique.test.ts` refuse la liste qui la recopie.
- **Un tracé non vide appartient à un seul signe de `SIGNES`.** Une autre famille le déclare dans `REPRISES_DE_SIGNES`, avec son libellé. Autorité : `src/referentiel/signes.ts`. Tests : `tests/signes.test.ts`.
- **Les formes d'alerte restent dans le socle.** Les cinq `FORMES` de `packages/plugin-socle/src/ui/Alerte.ts` ne se recopient pas dans `SIGNES`. Un signe se dessine sur une grille de 16, sauf s'il déclare `grille`, et `hauteur` quand elle n'est pas carrée. Autorité : `src/referentiel/signes.ts`. Tests : `tests/signes.test.ts`.
- **Chaque signe dit son emploi, chaque famille sa pose.** `emploi` dit quand prendre le signe et lequel prendre à sa place, `pose` la fonction du socle, les tailles, la teinte et le nom accessible. Ce sont des phrases pour un lecteur : le socle n'en dérive rien par code. `POSE_DES_ALERTES` décrit la pose des alertes, dont les formes restent au socle. Autorité : `src/referentiel/signes.ts`. Tests : `tests/signes.test.ts`.
- **`SIZE_VALUES` est la projection de `REGISTRE_TAILLES` (identifiants et formes tolérées), et `estUneValeurDesactivee` lit `REGISTRE_ETATS` par `termeReconnu`.** `tiny` est toléré de `xs`, `huge` de `xl`. Un axe dont toutes les valeurs sont dans `SIZE_VALUES` se publie `size` : un axe `Size=Tiny|Huge` reste `size`. Autorité : `src/referentiel/vocabulaire.ts`, `src/format/names.ts` `estUneValeurDesactivee`. Tests : `/tests/referentielUnique.test.ts`, `tests/valeurDesactivee.test.ts`, `tests/referentiel.test.ts`.
- **Après une modification du référentiel, relancer les tests, régénérer la vue illustrée (`generer-donnees-referentiel.ts`), régénérer la planche du moteur (`npm run planche --workspace ucm-couleur`) si le moteur ou ses crans changent, et changer la version de `@ucm-kit/core`.**
- **Un composant imbriqué se classe par `sorteDeLImbrique`, dans cet ordre : dépendance (`.componentRules` le nomme), wrapper de dimensions (dimensions de layout liées), pièce interne (préfixe `.` ou `_`), détail.** Le socle et le relevé d'Architect relèvent les faits, puis appellent la fonction ; aucun ne teste le préfixe ni les dimensions pour classer. Une liaison que l'instance tient sans changement de son composant principal n'est jamais jugée (C80, C20, C19), quelle que soit la sorte ; une surcharge de l'hôte l'est et vise un token de l'hôte. Autorité : `src/referentiel/composition.ts` `sorteDeLImbrique`, `src/controles/couche.ts` `controlerCouchesParEtapes`, `src/controles/mapping.ts` `controlerMappingParEtapes`. Tests : `tests/composition.test.ts`, `tests/controles-composant.test.ts`, `packages/plugin-socle/tests/imbriquesParLeKit.test.ts`, `packages/plugin-architect/tests/imbriquesParLeKit.test.ts`.
- **Une valeur de variant s'écrit en toutes lettres, son token en abréviation.** Le variant prend une majuscule à chaque mot (`Small`, `Extra Large`, `Danger`), le token des minuscules (`sm`, `xl`, `danger`). `ecritureDuVariant` passe de l'un à l'autre, et `S`, `M`, `L`, `sm`, `Middle` et `Error` reçoivent une correction vers le mot entier. `segmentDeToken` change le point et la barre en tiret. Autorité : `src/referentiel/ecriture-des-mots.ts`, `TAILLES_DE_VARIANT` de `src/referentiel/vocabulaire.ts`. Tests : `tests/valeursDeVariant.test.ts`.
- **Le rôle d'un nom d'axe vient du référentiel.** `NOMS_D_AXES` et `NOMS_D_AXES_FRANCAIS` le donnent, et un interrupteur de `INTERRUPTEURS` ne pilote aucun segment. Autorité : `src/referentiel/architecture.ts`, `axeDePropriete` de `src/controles/nommage.ts`. Tests : `tests/rolesDesNomsDAxe.test.ts`.
- **Un layer est une icône, un anneau ou un séparateur selon `src/referentiel/layers.ts`, jamais selon une expression propre à un contrôle.** Une icône est l'instance d'un composant dont le nom dit icône, l'instance qu'une propriété d'échange d'instance pilote sous un nom d'icône, ou un VECTOR ou BOOLEAN_OPERATION dont le nom contient un mot entier de `MOTS_D_ICONE`. Un FRAME ou un TEXT n'en est jamais une. Un anneau est nommé `Ring` ou `Focus ring`, ou lié à un token de rôle `ring`. Seuls `divider`, `ring` et `icon` désignent un layer par son nom. Autorité : `src/referentiel/layers.ts`. Tests : `tests/definitionsDeLayer.test.ts`, `tests/iconeDansLesControles.test.ts`.
- **Une faute se juge sur la longueur du mot, jamais sur le nombre d'emplois ni sur la place.** Un mot de 7 lettres au moins à une lettre d'un terme connu (échange compris), ou de 8 lettres à deux lettres, donne une question de faute vers le terme UCM, même si le terme manque au fichier. La référence tolérée vaut son terme UCM, et une négation n'est jamais une faute. Le dictionnaire (`FORMES_D_UN_MEME_MOT`, `MOTS_DISTINCTS`) classe les couples : un couple absent des deux, de deux mots hors vocabulaire à une lettre près et au seuil de 7 lettres, devient une question `ecriture-proche`. Un renommage de forme tolérée bloqué par collision, un synonyme seul au terme UCM unique et un pluriel de terme sans singulier donnent une question de paire. `npm run stress:f1 -- --faux-positifs` fixe les seuils. Autorité : `src/referentiel/questions.ts`, `src/referentiel/termes-connus.ts`, `src/referentiel/vocabulaire.ts`. Tests : `tests/questionsReferentiel.test.ts`, `tests/dictionnaireDuVocabulaire.test.ts`.
- **Le renommage est idempotent.** Appliqué à ses propres sorties, il ne renomme rien : `ecritureStable` (`src/referentiel/lexique.ts`) reprend l'écriture d'un segment jusqu'à ce que sa relecture ne la change plus. Borne : `BRANCHES_MAXIMALES_PAR_CLE` (50) limite les branches parallèles comparées par clé, pour le coût en paires. Tests : `tests/lexiqueReferentiel.test.ts`, `tests/stressF1Harnais.test.ts`.
